# 🌾 Swaraja — स्वराज
### AI-Powered Agriculture App for Maharashtra Farmers

Swaraja is a web app built for farmers in Maharashtra, India.
Everything is in **Marathi language**.

## Features
- 📊 Live mandi prices from major Maharashtra markets
- 🔬 AI plant disease detection (upload photo → get diagnosis)
- 🌱 Crop advisor based on soil, season & district
- 🌤️ 7-day weather forecast with farming advice
- 🤖 AI chatbot in Marathi with voice input/output

## Tech Used
HTML • CSS • JavaScript • Claude API (Anthropic) •
Agmarknet Govt API • OpenWeatherMap API • Web Speech API
